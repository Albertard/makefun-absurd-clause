# The Soul Retention Clause

A program that writes exactly one line to `/output/entry.txt` — a single original English sentence, at most 200 characters, phrased as a clause that could sit buried deep inside a terms-of-service agreement. Built for the make.fun competition **"The Absurd Clause Contest"** (`u-donrulezz-the-absurd-clause-contest-035cc0f1`).

## The line

> By using this service, you agree that your soul may be retained for quality-assurance purposes and returned, if at all, in a plain brown envelope within 6-8 weeks.

The line works because it opens like real boilerplate — "By using this service, you agree that…" — and the absurdity arrives mid-sentence: your soul, retained for quality assurance, then posted back in a plain brown envelope, maybe. The joke needs no setup: the register does the ambush, and the concrete image (a soul in a brown envelope, 6–8 weeks) is specific enough to picture and short enough to retype. At 163 characters it fits the 200-character gate with room to spare.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
